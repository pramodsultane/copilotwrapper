# Contributing to copilotwrapper

Thank you for contributing.

## Clean-Room Contribution Rules

All contributors must comply with the clean-room policy.

- Write original code only.
- Do not copy code, structure, or internal logic from other projects.
- Use permissive dependencies only (MIT, Apache-2.0, BSD, ISC).
- Include evidence of testing in pull requests.

## Required Pull Request Attestation

Include this statement in your pull request description:

"I certify that this contribution is an original implementation authored under clean-room rules and does not contain copied or structurally mirrored proprietary code."

## Required Pull Request Content

- Problem statement
- Independent design rationale
- Test steps and observed results
- Dependency/license impact

## Code of Conduct

By participating, you agree to maintain a respectful and inclusive environment.
